# prova-dsw
Repositório para a prova da disciplina de Desenvolvimento de Sistemas Web

### Clone o repositorio em:
<code>git clone https://github.com/NicolasRaony06/prova-dsw.git</code>

# Rodar Aplicação
### 1. Criar ambiente virtual
Rode o comando no diretorio do projeto
<code>python -m venv venv</code>

<hr>

### 2. Instalar pacotes
Rode o comando no diretorio do projeto
<code>pip install -r requirements.txt</code>

<hr>

### 3. Iniciar servidor django
Rode o comando no diretorio do projeto
<code>python manage.py runserver</code>

Acesse via: http://127.0.0.1:8000
